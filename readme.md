# 🏠 House Price Prediction (Regression ML Project)

본 프로젝트는 Kaggle House Prices 데이터를 이용하여  
집값을 예측하는 **회귀 모델(Regression)** 머신러닝 프로젝트입니다.

## 📌 사용 모델
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## 📌 기능
- 데이터 전처리 (결측치 처리, 원핫 인코딩, 스케일링)
- 모델 3종 학습 및 성능 비교
- RMSE, MAE 계산
- 학습된 모델 저장
- Streamlit 웹앱으로 예측 실행
